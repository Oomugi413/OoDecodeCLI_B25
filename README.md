# OoDecodeCLI_B25

Linux上で録画TS/M2TSを、ARIB STD-B25復号する小さな独立ツールです。Python標準ライブラリのGUIとCLIの両方を備えています。

## 動作の流れ

入力が `.ts` または `.m2ts`（大文字も可）であることを最初に確認します。たとえば `番組.ts` を指定すると、次の順に処理します。

1. `番組.ts` が存在し、リネーム先（および再開時の出力先）がまだ存在しないことを確認。
2. 元ファイルを `番組.ts.ts` へリネーム。
3. `arib-b25-stream-test` の標準入力へ `番組.ts.ts` を渡し、同じディレクトリの一時ファイルへ復号。
4. 復号が成功したら、出力を `番組.ts` へ移動。
5. `ffprobe` で旧ファイルと新ファイルの長さを比較し、差が30秒以内なら成功と表示。

出力先がすでにある場合、またはリネーム先がすでにある場合は、既定ではスキップします。復号に失敗した場合、長さが許容範囲外の場合、ffprobeが実行できない場合も、入力・リネーム済みファイル・出力ファイルを自動削除しません。復号途中の `.part` ファイルも調査用に残します。

処理は複数ファイルを受け取った順に1件ずつ行います。同じファイルを再開したいときは、残った `番組.ts.ts`（または `番組.m2ts.ts`）を直接指定できます。

## 必要なもの

以下が `PATH` から実行できる必要があります。

- `arib-b25-stream-test`
- `ffprobe`（FFmpegに含まれます）
- Python 3.10以降とTkinter（GUIを使う場合。Debian/Ubuntuなら通常 `python3-tk`）
- `zenity`（Linux GUIのファイル選択画面。利用できない場合はTkの選択画面へフォールバック）
- `arib-b25-stream-test` がリンクする `libaribb25`（通常はパッケージの実行時依存）

確認例:

```bash
command -v arib-b25-stream-test
command -v ffprobe
ldd "$(command -v arib-b25-stream-test)" | grep -i aribb25
python3 -c 'import tkinter; print("Tkinter OK")'
zenity --version
```

`arib-b25-stream-test` や `ffprobe` が標準の `PATH` にない場合は、環境変数でも指定できます。

```bash
export B25_DECODER=/path/to/arib-b25-stream-test
export FFPROBE=/path/to/ffprobe
```

またはCLIで `--decoder` と `--ffprobe` を指定してください。

## 起動とドラッグ＆ドロップ

### GUI（推奨）

プロジェクト内で:

```bash
cd ~/git/OoDecodeCLI_B25
./run.sh
```

ウィンドウの「ファイル追加…」で複数ファイルを選べます。GNOME/Wayland環境ではZenityのGTK選択画面を使用します。Tk 8.6標準選択画面で深いディレクトリの上層メニューがクリック解放時に閉じる問題を回避するためです。直前に選択したフォルダは次回も引き継がれます。

デスクトップ上のランチャーへファイルをドロップして起動時の一覧へ渡すこともできます。ランチャーを一度登録するには:

```bash
cd ~/git/OoDecodeCLI_B25
./install.sh
```

アプリケーション一覧に **OoDecodeCLI B25** が追加されます。そこへTS/M2TSを複数まとめてドラッグし、ダブルクリックでも起動できます。デスクトップ環境によっては、登録後にログアウト/ログインまたはアプリ一覧の更新が必要です。

この環境のプロジェクト直下には、すぐ試せる `OoDecodeCLI_B25.desktop` も置いてあります。ファイルマネージャーが「信頼する/起動する」と確認した場合は許可してください。

### CLI

端末から複数ファイルを指定する場合:

```bash
./run.sh --cli \
  '/mnt/recording/番組A.ts' \
  '/mnt/recording/番組B.m2ts'
```

リネームや復号をせず、拡張子とファイル名の競合だけ確認するには:

```bash
./run.sh --cli --dry-run '/mnt/recording/番組A.ts'
```

終了コードは、すべて成功またはスキップなら `0`、1件でもエラーなら `1` です。

## 安全上の注意

- 現在のファイル名と同じ出力先があるときは上書きしません。
- リネームは復号開始前に行います。失敗後に元の名前へ自動で戻すことはありません。そのため、エラー時は表示された `.ts.ts` と `.part` を確認してから手動で判断してください。
- 長さの判定は `abs(新しい長さ - 元の長さ) <= 30秒` です。判定に失敗しても出力は削除されません。
- このツールは入力ファイルを削除しません。復号後も暗号化されたリネーム済み入力と復号済み出力の両方が残ります。
